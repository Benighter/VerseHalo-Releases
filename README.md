# VerseHalo Releases

This is the official public download and automatic-update channel for **VerseHalo**, a Windows scripture, song, image, video, dictionary, and browser presentation studio.

Download the newest installer from [Latest release](https://github.com/Benighter/VerseHalo-Releases/releases/latest).

VerseHalo verifies every downloaded installer against the SHA-256 digest published by GitHub and waits until the operator is off air before offering installation.

For support, open an issue in this repository. Do not attach private church media, passwords, API keys, or copyrighted Bible database files.
